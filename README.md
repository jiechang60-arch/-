# 赵云与阿斗 · 联机版

## 本次玩法对齐

- 武将“赵云”已改名为“常帅”，旧武器装备存档会自动迁移。
- 武将拥有独立攻击特性，击杀小兵获得经验并最高升至 5 级。
- 战斗扩展为 20 波、每 5 波首领；装备品质概率随波数提高，首领额外加成。
- 道具采用 2 个主动栏与 6 类永久被动效果，库存不会按天重置。
- 农民每 8 秒产粮，可同等级二合一升级，等级越高产量越多。
- 部分装备增加攻击速度、射程或控制效果，不再只有伤害加成。

一款以三国"长坂坡救主"为题材的文字合成塔防小游戏。本项目在开源复刻版基础上
新增了 **跨网联机对战**（WebRTC P2P）和 **永久存档**（道具/养成永不过期），
并把皮肤改为三国主题（六武将、二十四件三国兵器、五大战场地图）。

> 玩法核心：把字牌拖上白色空地布阵。相同兵种相同等级二合一升级，单字碎片拼出
> 武将姓名即可觉醒（常帅·贯穿、张飞·眩晕、关羽·斩杀、黄忠·速射、马超·冲阵、
> 刘备·仁德光环）。敌人沿 S 形小路行进攻向"阿斗"，三颗心打完即输。

## 主要功能

- **完全不限体力**：开始单机或好友对战都不消耗体力，不设每日次数和恢复等待
- **完整单机模式**：保持原版 AI 对手，难度随段位变化（11 级军职 / 5 阶 / 5 星）
- **好友联机（跨省可用）**：基于 PeerJS（WebRTC P2P + 公共信令 + TURN 中继）
  - 房主创建 6 位房间码，挑战者输入房间码加入
  - 双方各管自己半场，操作零延迟；对方半场以 ~6Hz 快照镜像显示
  - 服务器只用于一次性的"牵线"配对，**对局流量不经过任何服务器**
  - 内置中国可达 STUN（小米）+ 公益 TURN（openrelay）兜底，跨省 NAT 穿透有保障
- **永久存档**：武将/兵器/军职/货币全部 localStorage 永久保存
  - 技能道具（农民/招贤令/陨石/攻速符/神兵符）库存**永不重置**
  - 已获得武器永久入库；可随时拖给不同武将，替换下来的武器自动回库
- **主动/被动道具分离**：招贤令、陨石、攻速符、神兵符由玩家点击使用；持有农民后每 15 秒自动刷新一个农民（最多 4 个），不消耗库存
- **武将成长与专属攻击**：击杀敌军获得经验并升至 Lv.5；赵云直线贯穿突刺，张飞范围震慑并眩晕，其他武将也拥有独立弹道和技能
  - 过波奖励 + 击杀 Boss 概率获得道具；对局内随时调用
- **24 件三国兵器**：青龙偃月刀、丈八蛇矛、龙胆亮银枪、虎头湛金枪、万石宝弓、
  双股剑（6 神器专属）+ 珍品 6 + 良品 5 + 凡品 5
- **5 大三国战场**：长坂坡 / 当阳道 / 落凤坡 / 赤壁 / 桃园

## 部署到公网（你和你哥在不同城市也能玩）

1. 注册 GitHub 账号（免费，2 分钟）：<https://github.com/join>
2. 新建一个仓库（建议公开，便于开启 Pages）：
   - 名称自取，例如 `zyad-pvp`
   - 选 **Public**（Pages 公开服务免费；仓库只有静态文件，无后端）
   - 不要勾选任何初始化选项
3. 把本目录里**除** `node_modules/`、`test-shots/`、`pw.log`、`.gitignore` 之外的所有
   文件上传到仓库根目录（直接拖拽文件到 GitHub 上传页面）。最小文件集：
   - `index.html`
   - `libs/peerjs.min.js`（92 KB）
   - `js/*.js`（17 个模块）
   - `audio/*.wav`（9 个音效）
   - `server.cjs`（可选，本地测试用，无需上传）
4. 开启 Pages：仓库页 → **Settings** → **Pages** → Source 选 **Deploy from a branch** →
   Branch 选 `main` / root → Save。约 30 秒后给你一个形如
   `https://<你的用户名>.github.io/zyad-pvp/` 的网址。
5. 把这个网址发给你哥，两人各自用**手机或电脑浏览器**打开。
6. 一人点"好友联机 → 创建房间"得到 6 位房间码（截图发微信即可），另一人输入码
   点"加入房间" → 两人都按"进入对局"。

> 国内访问 github.io 偶尔慢/不稳。若不便访问，可改部署到 Cloudflare Pages
> （免费、可绑定域名），步骤几乎一样：连 GitHub → 自动构建部署。

## 联机操作说明

- **波次同步**：房主决定开波时机，客机自动跟随；波次队列、地图都按"对局种子"
  生成（双方完全一致，公平开局）
- **道具栏**：左侧 5 个竖排小方块就是你的道具（×2、×1 表示剩余数量）
  - 招贤令 / 攻速符：点一下立即生效
  - 农民 / 陨石 / 神兵符：点一下进入瞄准模式，再点地图/武将释放
- **断线重连**：关闭页面后重新打开同一网址即可

## 开发备注

- 联机架构：双方各模拟自己半场（操作零延迟），每 150ms 互发半场合牌（含单位
  血量/地图路径）；对方半场以 6Hz 快照镜像显示
- 无任何后端服务器：游戏数据仅在浏览器 localStorage；对局流量 WebRTC P2P
- 联机依赖：PeerJS 公共信令 + STUN（小米/Google/Twilio）+ TURN（openrelay）
